# AreaEffect

> Minecraft · 区域视觉效果模组 · 当前版本 **1.4.0**

在服务端划定区域，为区域指定「感知亮度」（CIE L\*）。玩家进入区域时画面平滑过渡到目标亮度，离开时平滑恢复——纯客户端画面效果，不改变真实光照。

---

## 简介

AreaEffect 让你在服务端创建区域，并为每个区域指定一个**目标感知亮度**（CIE L\*，0–100）。玩家进入区域时，客户端会把画面光照平滑过渡到该亮度；离开时再平滑恢复到原始画面。目标亮度高于环境时区域变亮——不必摆放发光方块就能提亮建筑内部、消除难看的暗角；低于环境时则让区域变暗。

效果完全实现在**客户端光照贴图的接收端**，因此：

- **只是画面效果**：不改变方块的真实光照等级，不影响阳光传感器的读数，也不影响刷怪。
- **不读写玩家的 Gamma 设置**：早期版本曾直接修改 Gamma，现已弃用该做法，改为在光照贴图上传前叠加统一的亮度偏移。

模组名 AreaEffect 来自其可扩展的「区域效果」架构——一个区域可挂载多种效果，当前内置的是**亮度效果**。

## 特性

1. **7 种选区形状**：长方体、全高方柱、圆柱、全高圆柱、球体、多边形柱、全高多边形柱。手持选区工具（默认木斧）时，`Shift` + 右键空气可循环切换形状，屏幕中央会短暂显示当前形状。
2. **每区域独立的亮度与过渡**：目标亮度 CIE L\*（0–100）、过渡时长（0–60 秒，`0` 表示不过渡、瞬间到位）。
3. **自绘线框**：选区与已存区域的线框均由本模组绘制，无需 WE-CUI 等外部模组。
4. **区域管理面板**（默认 `J` 键）：跨维度区域列表 / 传送 / 删除 / 修改亮度与时长（拖动滑条实时预览）/ 备注 / 线框开关。
5. **精确冲突判定**：区域之间不允许重叠（方块级精确检测）；创建时若冲突，会自动显示与之冲突区域的线框。
6. **区域备注**：每个区域可附带备注，最长 60 字符。
7. **随存档持久化**：区域数据保存在 `<存档目录>/areaeffect.dat`（一个世界一个文件，临时文件 + 替换的原子写入）；选区工具等模组配置在 `config/areaeffect.cfg`。
8. **仅 1.7.10**：本分支只支持 Minecraft 1.7.10（需 Forge）；其它 MC 版本由对应分支/文件提供。

## 操作

**选区工具**（默认木斧，可用 `/aef tool` 改成任意手持物品）：

| 操作 | 二点形状（长方体 / 方柱 / 圆柱 / 全高圆柱 / 球体） | 多边形形状（多边形柱 / 全高多边形柱） |
| --- | --- | --- |
| 左键方块 | 设置起点（球体/圆柱为圆心） | 追加一个顶点 |
| 右键方块 | 设置终点（球体/圆柱为半径点） | 撤回上一个顶点 |
| 右键空气 | —（无效果） | 撤回上一个顶点 |
| `Shift` + 右键空气 | 循环切换选区形状 | 循环切换选区形状 |

多边形顶点满 3 个即自动闭合、可创建，无需手动闭合；单个选区最多 64 个顶点。

**按键**（可在控制设置里改键）：

| 按键 | 功能 |
| --- | --- |
| `J` | 打开区域管理面板 |
| `K` | 开关选区线框显示 |

## 指令

所有指令仅限 **OP 权限等级 2+** 执行；在服务端创建/修改区域同样需要该权限——非 OP 玩家即使手持选区工具也无法选点。指令名 `/areaeffect`，别名 `/aef`。

```text
/aef pos1                    设置当前位置为选区起点
/aef pos2                    设置当前位置为选区终点
/aef create [亮度] [时长]    按当前选区创建区域
                             亮度 = 目标亮度（CIE L*，0-100，默认 100）
                             时长 = 过渡时长（秒，0-60，默认 1；0 = 瞬间）
/aef tool                    空手：查看当前选区工具；手持物品：把选区工具设为该物品
```

> 区域管理（列表 / 传送 / 删除 / 修改亮度与时长 / 备注 / 线框）已迁移到客户端面板（按 `J`），不再提供对应指令。
