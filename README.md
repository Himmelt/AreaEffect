# AreaEffect

> Minecraft · 区域视觉效果模组 · 当前版本 **1.4.0**

在服务端划定区域，为区域挂载「区域效果」（亮度 / 雾 / 天空）。玩家进入区域时画面平滑过渡到目标效果，离开时平滑恢复——纯客户端画面效果，不改变真实光照。

---

## 简介

AreaEffect 让你在服务端创建区域，并为每个区域挂载一种或多种**区域效果**。玩家进入区域时，客户端把画面平滑过渡到该效果；离开时再平滑恢复。区域允许任意重叠，重叠处同种效果按**权重**取胜（权重相同则取后创建的那个区域）。

内置三种效果，一个区域内每种至多一个：

| 效果 | 参数 | 说明 |
| --- | --- | --- |
| **亮度** | 目标亮度（CIE L\*，0–100） | 接管客户端光照贴图，把区域画面统一到目标感知亮度。高于环境即变亮——不必摆放发光方块就能提亮建筑内部、消除难看的暗角；低于环境则变暗 |
| **雾** | 雾色 RGB、起雾距离、过渡距离、尘粒数量 | 接管视野雾：起雾距离之内完全无雾，其外按过渡距离线性加浓，走完过渡距离即 100% 雾色 |
| **天空** | 天空色 RGB | 接管天空穹顶，保留太阳、月亮、星空与日出日落霞光 |

三者共有三个公共参数：**权重**（重叠区域内谁生效）、**过渡时长**（0–60 秒，进出区域与改参数时的平滑耗时，`0` 表示不过渡、瞬间到位）、**生效时段**（始终 / 游戏时间 / 现实时间，后两者可设定区间并支持跨午夜）。

三条实现约定：

- **只是画面效果**：不改变方块的真实光照等级，不影响阳光传感器的读数，也不影响刷怪；雾与天空同样只影响画面。
- **不读写玩家的 Gamma 设置**：早期版本曾直接修改 Gamma，现已弃用该做法，改为在光照贴图上传前叠加统一的亮度偏移。
- **天空效果只在地表维度生效**：下界与末地原版本就不绘制天空，本模组同样不接管；雾与亮度不区分维度。

模组名 AreaEffect 来自其可扩展的「区域效果」架构——新增一种效果只需实现 `AreaEffect` 子类，并在 `EffectTypes`（序列化）与 `EffectRenderers`（客户端运行时）各接一条分支。

## 特性

1. **8 种选区形状**：长方体、全高方柱、圆柱、全高圆柱、球体、多边形柱、全高多边形柱，以及**整个维度**（无视选区、覆盖当前维度）。手持选区工具（默认木斧）时，`Shift` + 右键空气可循环切换形状，屏幕中央会短暂显示当前形状。
2. **三种区域效果**：亮度 / 雾 / 天空，一个区域可同时挂载，各自带权重、过渡时长与生效时段（见上文表格）。
3. **区域允许任意重叠**：不做冲突校验、不必先清空重叠区；重叠处同种效果按权重取胜，同权取后创建者，结果恒定、同帧不抖动。
4. **自绘线框**：选区与已存区域的线框均由本模组绘制，无需 WE-CUI 等外部模组。
5. **区域管理面板**（默认 `J` 键）：跨维度标签页 / 区域列表 / 传送 / 删除 / 增删效果与调参（拖动滑条实时预览）/ 备注 / 线框开关。
6. **区域备注**：每个区域可附带备注，最长 60 字符。
7. **随存档持久化**：区域数据保存在 `<存档目录>/areaeffect.dat`（一个世界一个文件，临时文件 + 替换的原子写入）；选区工具等模组配置在 `config/areaeffect.cfg`。
8. **仅 1.7.10**：本分支只支持 Minecraft 1.7.10（需 Forge）；其它 MC 版本由对应分支/文件提供。

## 操作

**选区工具**（默认木斧，可用 `/aef tool` 改成任意手持物品）：

| 操作 | 二点形状（长方体 / 全高方柱 / 圆柱 / 全高圆柱 / 球体） | 多边形形状（多边形柱 / 全高多边形柱） |
| --- | --- | --- |
| 左键方块 | 设置起点（球体/圆柱为圆心） | 追加一个顶点 |
| 右键方块 | 设置终点（球体/圆柱为半径点） | 撤回上一个顶点 |
| 右键空气 | —（无效果） | 撤回上一个顶点 |
| `Shift` + 右键空气 | 循环切换选区形状 | 循环切换选区形状 |

多边形顶点满 3 个即自动闭合、可创建，无需手动闭合；单个选区最多 64 个顶点。
「整个维度」形状无需任何选点：切到它直接 `/aef create` 即得一个覆盖当前维度的区域（它没有边界，因此不画线框）。

**按键**（可在控制设置里改键）：

| 按键 | 功能 |
| --- | --- |
| `J` | 打开区域管理面板 |
| `K` | 开关选区线框显示 |

## 指令

所有指令仅限 **OP 权限等级 2+** 执行；在服务端创建/修改区域同样需要该权限——非 OP 玩家即使手持选区工具也无法选点。指令名 `/areaeffect`，别名 `/aef`。

```text
/aef pos1     设置当前位置为选区起点
/aef pos2     设置当前位置为选区终点（球体 / 圆柱下即半径点）
/aef create   按当前选区创建一个不带任何效果的空区域
/aef tool     空手：查看当前选区工具；手持物品：把选区工具设为该物品
```

> 区域创建时不含任何效果，效果（亮度 / 雾 / 天空）在管理面板（按 `J`）里添加与调参。
> 区域管理（列表 / 传送 / 删除 / 效果与参数 / 备注 / 线框）均在该面板内，不再提供对应指令。
